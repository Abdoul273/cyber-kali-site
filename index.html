Questions fréquentes

Comment installer l'application ?
  1. Touchez « Télécharger pour Android » puis ouvrez le fichier cyber-kali.apk (barre de notifications ou dossier Téléchargements).
  2. Si le téléphone affiche « Pour votre sécurité… », touchez Paramètres puis autorisez Chrome (ou votre navigateur) à installer des applications.
  3. Revenez en arrière et touchez Installer.
Faut-il un ordinateur ou Kali Linux ?

Non, pour lire les cours le téléphone suffit. Pour pratiquer les commandes, il vous faudra ensuite Kali Linux (sur un PC, dans une machine virtuelle ou avec des labs en ligne) : le premier module explique comment l'installer.

L'application est-elle payante ?

Non. Pour l'instant, tous les modules, y compris ceux marqués Premium, sont accessibles gratuitement.

Faut-il Internet ?

Une connexion est utile pour les CVE et l'actualité en direct. Les cours eux-mêmes sont intégrés à l'application.

Ai-je le droit d'utiliser ces techniques ?

Uniquement sur vos propres machines, sur des labs prévus pour ça (TryHackMe, Hack The Box…) ou avec l'autorisation écrite du propriétaire du système. Attaquer un système sans autorisation est illégal. Cyber Kali apprend à comprendre les attaques pour mieux s'en défendre.

Pourquoi l'application n'est pas sur le Play Store ?

Elle est distribuée directement ici pour le moment. Ne l'installez que depuis cette page ou depuis un lien envoyé par l'auteur.
